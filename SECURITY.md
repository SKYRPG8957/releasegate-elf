# Security

This alpha tool parses potentially hostile data. Run it in an isolated environment with CPU/memory limits and no secrets when inspecting untrusted releases. It does not extract archives or execute payloads, but it is not a sandbox or malware scanner.

No hosted repository or private advisory channel has been configured yet. Before publishing, the maintainer should enable private vulnerability reporting and update this file with a verified channel. Do not publicly post working exploits against a deployed service or private payloads.
